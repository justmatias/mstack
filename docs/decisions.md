| 12 | 2 | `no-manual-init-boilerplate` ships as `warning` and is deliberately narrow: classes whose only method is `__init__`, whose `__init__` only contains `self.x = x` (and comments), and that do not subclass an `*Exception`/`*Error`. | 15 | 3 | Verified `ast-grep-ignore` for Python: `# ast-grep-ignore: <id>[, <id>]` on the line directly above the code, or trailing on the same line. A bare `# ast-grep-ignore` suppresses every rule, so `check_exceptions.py` rejects it. The `# rule-exception:` comment goes on the line above (above the code line for the trailing form). Comments are found with `tokenize`, so strings that contain the marker are not mistaken for exceptions. | [VERIFY] item. ast-grep also reports `unused-suppression` for an ignore that suppresses nothing. |
