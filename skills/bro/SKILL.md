# Bro

> **Principles (always apply):** (1) **English only**: everything you write or generate is in English, including the restatement, even when the source is not. (2) **Practices, not domain**: the restatement keeps the meaning of the last message, never adds domain details, values or URLs it did not already contain. Details: [../sync/references/principles.md](../sync/references/principles.md).

Restate your last message. Stop using jargon and speak coherently. State it more simply and concisely, like one human talking to another.
